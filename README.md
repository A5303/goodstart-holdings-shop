# GoodStart Holdings - E-commerce Store

A modern e-commerce website for GoodStart Holdings featuring M-Pesa integration.

## Features

-  Product catalog with categories
-  Shopping cart with localStorage
-  M-Pesa payment integration
-  Cash on delivery option
-  Order management
-  Responsive design
-  Fast and modern UI

## Technologies Used

- HTML5, CSS3, JavaScript
- Font Awesome Icons
- Local Storage API
- M-Pesa Daraja API (Simulation Mode)
