# GoodStart Holdings - E-commerce Store

A modern, responsive e-commerce website for GoodStart Holdings featuring M-Pesa payment integration and complete shopping cart functionality.

Live Demo
View Live Site(https://a5303.github.io/goodstart-holdings-shop/)

Features

Product Management
- 38+ products across multiple categories (Flour, Sugar, Cooking Oil, Soap, Beverages, Dairy)
- Product catalog with search and filter functionality
- Featured products section on homepage
- Product images and detailed descriptions

Shopping Cart
- Add/remove items with quantity controls
- Real-time cart updates with item count
- Persistent storage using localStorage
- Cart summary with subtotal, delivery fees, and total

Payment System
- M-Pesa integration with STK Push simulation
- Cash on delivery option
- Order confirmation with receipts
- Payment status tracking
  
 User Experience
- Fully responsive design for all devices
- Modern UI/UX with smooth animations
- Form validation and error handling
- Loading states and user feedback

 Technologies Used

- Frontend: HTML5, CSS3, JavaScript (ES6+)
- Icons: Font Awesome 6.0
- Storage: localStorage API
- Payments: M-Pesa Daraja API (Simulation Mode)
- Backend: Node.js, Express.js
